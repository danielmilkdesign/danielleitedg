## ⚡ Como Publicar no GitHub e Hospedar

### 1. Inicializar e Subir para o GitHub:
```bash
git init
git add .
git commit -m "feat: deploy portfolio Daniel Rodrigo Graphic Design & Art Direction"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
git push -u origin main
```

### 2. Ativar o GitHub Pages (Opcional):
1. No seu repositório no GitHub, vá em **Settings** > **Pages**.
2. Em **Source**, selecione a branch `main` e a pasta `/ (root)`.
3. Clique em **Save**. O site estará no ar em poucos segundos em `https://SEU_USUARIO.github.io/SEU_REPOSITORIO/`.

### 3. Deploy na Vercel (Recomendado):
1. Acesse [vercel.com](https://vercel.com) e conecte sua conta do GitHub.
2. Importe o repositório criado.
3. Clique em **Deploy**. A Vercel detectará automaticamente o arquivo `index.html`.
